JORNES GRÁFICA — WEBSITE

Ficheiros:
- index.html: estrutura e conteúdo do site
- style.css: estilos, cores e adaptação para telemóveis
- script.js: menu responsivo, ano automático e validação simples do formulário

Como abrir:
1. Extraia a pasta do ZIP.
2. Abra index.html num navegador moderno.

Personalização necessária:
- Troque o telefone e o e-mail de exemplo pelos contactos reais.
- Substitua os links # das redes sociais pelos perfis oficiais.
- O formulário funciona como demonstração no navegador, mas não envia mensagens.
  Para receber pedidos/feedback, ligue-o a um backend ou serviço de formulários.
- A imagem de fundo pode ser substituída no CSS na regra .hero.

Tecnologias: HTML5, CSS3 e JavaScript puro (sem frameworks).
